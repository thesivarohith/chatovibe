# 💬 ChatoVibe — AI-Powered Real-Time Chat App

A full-stack real-time chat application with Google Authentication and Gemini AI integration.

## ✨ Features
- 🔐 **Google OAuth** — secure one-click sign in via Gmail
- 💬 **Real-time messaging** — instant chat between users
- 🤖 **Gemini AI integration** — AI assistant built right into the chat
- 📱 Responsive UI for both desktop and mobile

## 🚀 Getting Started

```bash
git clone https://github.com/thesivarohith/chatovibe
cd chatovibe
npm install
npm run dev
```

## 🔑 Environment Variables
```
GOOGLE_CLIENT_ID=your_google_client_id
GEMINI_API_KEY=your_gemini_api_key
```

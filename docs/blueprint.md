# **App Name**: Realtime Relay

## Core Features:

- Google Authentication: Secure user authentication via Google Sign-In using react-firebase-hooks.
- Real-time Messaging: Send and receive text messages in real-time using Firestore.
- Message Storage: Store messages with sender information and timestamp in Firestore.
- Dynamic UI Updates: Automatically update the chat interface with new messages as they arrive.
- Auto-scrolling: Automatically scroll to the bottom of the chat to display the latest message.
- Message Animations: Implement smooth animations for incoming messages using react-flip-move.
- Sign out: Allow users to securely sign out of the application

## Style Guidelines:

- Primary color: Indigo (#4F46E5) to convey trust and stability.
- Background color: Light gray (#F9FAFB), a desaturated tint of indigo.
- Accent color: Violet (#8B5CF6), an analogous color to indigo, brighter and more saturated.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, machined, objective, neutral look.
- Use simple, outlined icons for clarity and visual appeal.
- Use a clean, responsive layout with clear separation of concerns. Current user messages aligned to right; others to left.
- Subtle animations for new messages to enhance user experience.
